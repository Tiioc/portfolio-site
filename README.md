# tylerbunn.netlify.app

Source for my portfolio site: **[tylerbunn.netlify.app](https://tylerbunn.netlify.app)**

Plain HTML and CSS, no framework, so it loads fast and is easy to keep up. Every project page has a working demo and a "see the code" page.

## Projects on the site
- **Inbox Owner:** an email triage demo that sorts a shared inbox into a queue, with written rules (SOP) for each case.
- **Member Billing:** a Google Sheets + Apps Script tracker that flags late and missing member payments. Includes a test script and answer key.
- **Order to Cash:** the earlier version of the billing work, kept as a record.
- **This site:** how the site itself was planned, built and put online.
- **tedock:** my current work, small cloud data tools on the Apify Store ([tedock.netlify.app](https://tedock.netlify.app)).

## Layout
| Folder | What's in it |
|---|---|
| `site/` | The live site, deployed as-is to Netlify |
| `member-billing/` | Apps Script code, build scripts and tests for the billing tracker (sample data only, all names and numbers are fake) |
| `tools/` | Small Python / JS helpers that build the code pages, check copy and render previews |
| `designs/` | Five homepage design options I compared before choosing the current one |
