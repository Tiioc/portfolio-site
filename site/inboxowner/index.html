InboxOwner

Tested on made-up data

1The problem

At The Paseo Club, every department's email came to the front desk. Nobody could tell who had answered what.

2What I made

A tool that gives every email an owner and shows who is still waiting. Claude Code wrote the code. I set the rules and tested every number.

3How it works

  1. Sorts new mailGuesses the topic or asks a person.
  2. Gives it an ownerOne person's name on each email.
  3. Times the waitHow long each email waits.

4What it found

So the fix is clear: give cancellation emails an owner and a reply deadline. The demo does that.

5What I learned

My first rules only fit old emails. One even matched "lease" inside "please." So I tested on 96 new emails it had never seen.
